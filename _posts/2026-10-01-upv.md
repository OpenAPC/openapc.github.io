We welcome the [Universitat Politècnica de València](https://www.upv.es) (UPV) as new contributing institution to OpenAPC!

The UPV operates an [institutional repository](https://riunet.upv.es/home) where cost data is provided using the [openCost metadata format](https://riunet.upv.es/server/oai/openaire4?verb=ListRecords&metadataPrefix=opencost&set=opencost). This data set has now been harvested and integrated by OpenAPC.

Contact person for the data set is [Francisco Jesus Martinez Galindo](mailto:pacomar@upv.es).


## Cost Data



The initial data set covers publication fees for 2,098 articles, total expenditure amounts to 5,011,336€ and the average fee is 2,389€.
